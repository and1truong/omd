# omd v0.1.0

**oh my day** now has a desktop preview with OMD as the notebook, Coconut as the trusted agent sidebar/MCP host, and shared Bridge tools for Lime in Chrome/Edge.

- **Desktop:** native Linux, macOS and Windows installers include Node 24.19.0, browser assets and the local agent host. Users do not need Node/npm for the installed app. The notebook stays in the native WebView's IndexedDB profile.
- **Agent tools:** explicit page IDs, notebook revisions and atomic idempotency receipts protect edits against stale approvals and duplicate retries, including after restart. Coconut and Lime use the same validated OMD commands.
- **Lifecycle:** startup opens OMD after its servers are ready; closing waits for pending edits. A failed save keeps the window open. The notebook and sidebar resize together, including Linux's GTK layout.
- **Browser:** the existing local-first web app, WebMCP support and portable web archives remain available. Lime is shipped as its verified extension ZIP, separately from the native application.

## Choose a download

| Platform/use | Asset |
| --- | --- |
| Linux desktop | `OMD_0.1.0_*.deb` |
| macOS desktop | `OMD_0.1.0_*.dmg` |
| Windows desktop | `OMD_0.1.0_*-setup.exe` |
| Browser/local server | `omd-v0.1.0.zip` or `omd-v0.1.0.tar.gz` |
| Lime for Chrome/Edge | `orchard-lime-extension-0.1.0.zip` |

Installer filenames identify the architecture. Desktop installers are **unsigned previews**; signing, macOS notarization and automatic updates are not configured. These are compiled app packages; GitHub's automatic source archives require building from source.

For the web archive, extract it and run `node start.mjs` with Node 22+, then open http://localhost:3000/. To install Lime, extract its ZIP and load the directory through Chrome/Edge's extension Developer mode.

Use `SHA256SUMS.txt` to verify every downloadable package and `omd-desktop-builds.json` for platform/Orchard/runtime provenance. Builds use the pinned `orchard-v0.1.0` release; the Orchard monorepo is not copied into OMD.

Browser and desktop notebooks use separate storage profiles. Export/import JSON to move your notebook, and keep exports as backups. Ordinary editing requires no agent credentials; agent features need a configured gateway and explicit consent/approval. Reminders run while OMD is open and catch up on reopening.

The release pipeline verifies web packaging, browser Bridge/Lime flows, native policy tests, all three installer builds and Linux native/installed-package acceptance before publishing the tag and complete asset set.
