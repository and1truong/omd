# omd v0.0.5

Fifth release of **oh my day**, a local-first notebook. Changes since v0.0.4:

- **Text toolbar on hover:** editing alone no longer opens the formatting bar.
  Hover over the block, or use Alt+F10 from the keyboard; Escape returns to the
  editor. Touch shows a bottom toolbar for the focused editor. Failed block
  insertion keeps its retry button visible.
- **Drag pages directly:** use the page-tree handle to reorder siblings or
  move a page and its descendants under another page. Drop in the empty tree
  area to move to the notebook root. Selection, content and undo/redo remain
  intact; cycles and overdeep moves are blocked.
- **Single-line headings:** Enter and Shift+Enter save the heading and finish
  editing. IME composition and failed writes retain focus and the draft.
- **Rich table cells:** bold, italic, strikethrough, inline code, lists and links
  work in cells, with a shared formatting bar and keyboard/touch access.
  Stable cell identity preserves the caret during neighboring updates and
  dimension changes; cells still store Markdown strings in JSON and WebMCP.
- **Cleaner sidebar and header:** the content-header sidebar opener appears
  only when the sidebar is closed. The saved-on-device footer text is removed.
- **Polished notifications:** compact cards, type-specific icons, light/dark
  colors, mobile wrapping and a clearer dismiss control. Reduced-motion
  preferences are respected; persistent errors retain their existing lifetime.
- **Checklist completion time:** checking records an ISO `completedAt` value
  and shows its local date/time. Unchecking clears it; checking again records
  a new time. Text edits and repeated `done=true` keep the original timestamp.
  Old completed items without a valid time show no date and are not backfilled.
- **Markdown clipboard formatting:** pasted Markdown applies its headings,
  marks, links (including references and email autolinks), lists, quotes and
  fenced code across text blocks, checklist items and table cells, even when
  the clipboard also carries an HTML source-code wrapper. Inline Markdown
  replaces the selected text without splitting its paragraph. Rich HTML and
  editor copies use the native paste path; code-block destinations stay literal.

These changes include PRs #47–#55. Existing v0.0.4 notebooks load directly;
the notebook JSON version and IndexedDB schema remain unchanged. Completion
timestamps, rich cells and pasted content persist through reload, notebook
history and JSON backups.

## Download and run

Download **omd-v0.0.5.zip** or **omd-v0.0.5.tar.gz** and extract the entire archive.
Use these named packages rather than GitHub's generated source archives. They
include the compiled app, browser libraries, fonts, styles, icons, dependency
inventory and third-party notices; no npm install, build or runtime CDN is needed.

With **Node.js 22+** installed, run in the extracted folder:

    node start.mjs

Open **http://localhost:3000/**. Static HTTP/HTTPS hosting is also supported.
Use **SHA256SUMS.txt** to verify the two packages. Data stays in browser storage;
JSON export/import transfers notebooks between origins or devices. Notifications
need permission and a running app; WebMCP requires native browser/extension support.

## Verification

The application source passed 118 unit tests, type checking, static/offline asset
checks and Chromium/WebKit regressions at `/` and `/omd`. Clipboard tests include
trusted Ctrl+C/Ctrl+V; Chromium exercises real mixed-MIME clipboard content, while
synthetic mixed-MIME events also cover HTML on WebKit's Linux clipboard. Tests
cover formatting, literal code, safe content, notebook history, failed writes,
JSON backups and real offline boot/paste.

The release workflow checks native browsers at both paths and extracts each
archive to verify its launcher and every bundled asset without `node_modules`
before publishing the tag and download assets.
