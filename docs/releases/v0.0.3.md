# omd v0.0.3

Third release of **oh my day**, a local-first notebook. Changes since v0.0.2:

- **Fixed / Fluid** page-width toggle in the top bar. Fixed centers the page
  at a maximum width of 900px; Fluid fills the workspace with side padding.
  The preference is remembered on this device without changing notebook data.
- Shift+Enter regression coverage after text composition ends, including
  preservation of composed text, sibling placement and typing into the focused
  new block. The user guide clarifies editor focus and input-method composition.
- Product-contract documentation now matches IndexedDB record storage, bundled
  Markdown editing and the 50 native WebMCP tools.

No Shift+Enter handler change is included: the reported failure was not reproduced
outside active input-method composition. Block creation remains suppressed while
composition is active to protect unfinished text. Finish composition before using
the shortcut; some input methods consume the first press to commit the word.

The release keeps notebook pages and subpages, Tiptap Markdown text editing,
headings, nested checklists, tabs, expandable blocks, accordions, reminders,
kanban, Mermaid, Excalidraw, system-aware themes, IndexedDB persistence with
undo/redo, JSON export/import, offline/PWA support and 50 native WebMCP tools.

## Download and run

Download **omd-v0.0.3.zip** or **omd-v0.0.3.tar.gz** below, then extract the entire
archive. These assets include the compiled app, all browser libraries and their
dependencies, fonts, styles, icons and third-party notices. They require **no npm
install, build step or runtime CDN**. GitHub's automatically generated source
archives are for development; use the named omd archives to run the app.

With **Node.js 22+** installed, open a terminal in the extracted folder and run:

    node start.mjs

Open **http://localhost:3000/**. The archive is platform independent; Node and the
browser are system prerequisites. Alternatively, serve the included dist folder
using a static HTTP server or static HTTPS hosting. SHA256SUMS.txt verifies the
two downloadable packages.

Hosted app: https://and1truong.github.io/omd/

Data stays in browser storage, separately for each origin. JSON export/import
transfers notebooks between the hosted and local app. Browser notifications need
permission and a running app; WebMCP requires native browser/extension support.
