# omd v0.0.2

Second release of **oh my day**, a local-first notebook. Highlights since v0.0.1:

- Tiptap Markdown text editing with a formatting toolbar and Markdown paste;
  Shift+Enter continues into a new text block and moves the cursor.
- Nested checklist items up to four levels; Enter adds a sibling, Tab/Shift+Tab
  indent and outdent, and moves carry whole subtrees.
- Inline block insertion: **+** controls appear on hover or focus above and
  between existing blocks.
- Checklist, checklist tree, editor and startup browser test coverage on
  Chromium and WebKit, at the origin root and under `/omd/`.

The release keeps notebook pages and subpages, text, headings, checklists, tabs,
expandable blocks, accordions, reminders, kanban, Mermaid, Excalidraw,
system-aware themes, IndexedDB persistence with undo/redo, JSON export/import,
offline/PWA support and 50 native WebMCP tools from v0.0.1.

## Download and run

Download **omd-v0.0.2.zip** or **omd-v0.0.2.tar.gz** below, then extract the entire
archive. These assets include the compiled app, all browser libraries and their
dependencies, fonts, styles, icons and third-party notices. They require **no npm
install, build step or runtime CDN**. GitHub's automatically generated source
archives are for development; use the named omd archives to run the app.

With **Node.js 22+** installed, open a terminal in the extracted folder and run:

    node start.mjs

Open **http://localhost:3000/**. The archive is platform independent; Node and the
browser are system prerequisites. Alternatively, serve the included dist folder
using a static HTTP server or static HTTPS hosting. SHA256SUMS.txt verifies the
two downloadable packages.

Hosted app: https://and1truong.github.io/omd/

Data stays in browser storage, separately for each origin. JSON export/import
transfers notebooks between the hosted and local app. Browser notifications need
permission and a running app; WebMCP requires native browser/extension support.
